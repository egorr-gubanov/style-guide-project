# Стайлгайд документации сервиса «Сосны»

Руководство устанавливает правила написания и оформления пользовательских инструкций
и документации для разработчиков веб-сервиса бронирования загородных домиков «Сосны».
Оно предназначено для авторов, редакторов и участников ревью.

## Область применения

В руководстве зафиксированы 19 обязательных правил: стиль изложения, терминология,
запись значений, структура документов, Markdown, изображения и примеры,
достоверность сведений и порядок проверки.

Сервис находится на стадии макета. Наличие поля или кнопки в Figma не подтверждает
реализацию обработки данных. Условия бронирования задаются требованиями к продукту;
стайлгайд определяет способ их описания.

## Как пользоваться

1. Определите аудиторию, назначение и статус документа.
2. Выберите [шаблон инструкции](templates/user-guide.md)
   или [шаблон требований](templates/requirements.md).
3. Проверьте термины по [глоссарию](glossary.md).
4. Примените правила из соответствующих разделов.
5. Проверьте содержание и выполните настроенные автоматические проверки.

Образцы применения правил: [заполнение формы](examples/booking.md)
и [проверка введённых данных](examples/form-validation.md).

## Статус сведений

- **Сведения из макета** — элементы, непосредственно представленные в Figma.
- **Предлагаемые требования** — условия, требующие согласования.
- **Согласованные требования** — принятые и зафиксированные решения проекта.
- **Проверенное поведение** — результаты проверки реализованной версии с указанием условий.
