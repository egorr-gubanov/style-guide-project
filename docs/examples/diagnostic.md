# Экран диагностики ЕГЭРывка

Экран показывает прототип диагностического задания по профильной математике.
Описание предназначено участникам проекта и рецензентам. В изученном компоненте
нет обработчиков выбора и сохранения ответа, поэтому прохождение теста не подтверждено.

## Открытие

После локального запуска приложения откройте путь `/diagnostic`.
Слева расположен блок прогресса, в основной области — задание и варианты ответа.

## Видимые элементы

- Заголовок **Вопрос 3 из 20** и номера заданий.
- Варианты ответа, сформированные из данных проекта.
- Кнопки **Сохранить ответ** и **Пропустить**.
- Кнопка **Завершить** и значение времени **45:00** в шапке широкого экрана.
- Демонстрационные показатели и полоса прогресса **15%**.

Надписи интерфейса сохранены точно. В авторском тексте пишем «15 %» по правилу P03.

## Ограничения реализации

Наличие кнопки не доказывает выполнение действия. В просмотренном компоненте
нет обработчиков для кнопок ответа, пропуска и завершения, а значения времени
и прогресса заданы статически. Таймер и сохранение ответа нельзя описывать как
работающие функции без дополнительного подтверждения.

Шапка с временем и кнопкой завершения скрыта на узком экране настройкой
`hidden md:flex`. Поведение разных размеров окна нужно проверить отдельно.
