# Оставшиеся действия для завершения лабораторной работы

Репозиторий `egorr-gubanov/style-guide-project` создан. В основной ветке находятся
стайлгайд, два образца документов, MkDocs, проверки и автоматическая публикация.
Раздел доступности подготовлен в отдельной ветке `codex/accessibility`.

## Обмен ревью: пункты 11.6–11.9 задания

1. Обменяйтесь с одногруппником ссылками на PR. Найдите свой PR в разделе Pull requests.
2. Оставьте не менее трёх содержательных комментариев к PR одногруппника.
   Проверяйте конкретные правила, понятность примеров и полноту проверки доступности.
3. Получите замечания к своему PR. Исправьте их новым коммитом в той же ветке
   и ответьте на каждое замечание с объяснением исправления.
4. Получите одобрение рецензента. После зелёных проверок объедините PR с `main`.

## Публикация после слияния: пункт 11.10

Дождитесь успешного запуска Documentation для коммита слияния. Откройте сайт
и убедитесь, что появился раздел «Доступность текста». Сохраните подтверждения
ревью, исправлений, одобрения, слияния и публикации для окончательной версии отчёта.

Текущее состояние PR не заменяет реальное независимое ревью. Не отмечайте
перечисленные действия выполненными до их фактического завершения.
