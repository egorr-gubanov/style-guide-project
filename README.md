# Стайлгайд документации сервиса «Сосны»

Руководство по написанию и оформлению документации веб-сервиса бронирования загородных домиков.

- [Сайт руководства](https://egorr-gubanov.github.io/style-guide-project/)
- [Макет сервиса в Figma](https://www.figma.com/design/Hrn06cbi1J6furVPfOIbso/ЛР1)
- [Правила внесения изменений](CONTRIBUTING.md)

## Содержание

Девять разделов с 23 правилами, глоссарий, два шаблона, два примера документов и источники.
Примеры относятся к будущей версии сервиса; их статус указан на соответствующих страницах.

## Локальная проверка

Требуются Git и Python 3.12. Из корня репозитория выполните:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python scripts/check.py
```

Проверка включает линтинг Markdown, правила ссылок и изображений, строгую сборку MkDocs
и проверку локальных ссылок готового сайта. Результат сборки находится в каталоге `site/`.

Для просмотра сайта выполните `python -m mkdocs serve` и откройте адрес, указанный в выводе.
