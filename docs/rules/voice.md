# Стиль изложения

## V01 Действие и исполнитель

**Обязательно.** Формулируйте инструкции глаголами: «Откройте», «Выберите»,
«Выполните». Указывайте исполнителя, если действие выполняет система.

До: «Необходимо осуществить запуск приложения».
После: «Выполните `npm run dev`».
Проверка: ручное ревью каждого шага.

## V02 Уважительный нейтральный тон

**Обязательно.** Обращайтесь к читателю на «вы» со строчной буквы. Исключайте
обвинения, жаргон, рекламные обещания и оценки сложности вроде «это элементарно».

До: «Вы неправильно всё настроили».
После: «Проверьте версию Node.js и повторите установку зависимостей».
Проверка: ручное ревью.

## V03 Одна мысль в предложении

**Рекомендуется.** Предложения длиннее 25 слов просматривайте отдельно.
Разделяйте условия, действия и результат, если их трудно понять с первого чтения.
Число 25 — внутренний ориентир проекта, а не требование внешнего стандарта.

До: «После установки зависимостей, которая нужна для запуска приложения,
перейдите к команде, позволяющей запустить сервер».
После: «Установите зависимости. Затем запустите сервер разработки».
Проверка: ручная оценка ясности; превышение не блокирует сборку.
