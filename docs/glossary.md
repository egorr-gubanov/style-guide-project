# Глоссарий

## Сервис «Сосны»

Проектируемый веб-сервис бронирования загородных домиков, для которого разработан макет интерфейса.

## Пользователь

Человек, взаимодействующий с интерфейсом сервиса.

## Гость

Человек, для которого предполагается проживание в домике.
Значение поля **Количество гостей** относится к числу проживающих.

## Домик

Объект размещения, сведения о котором представлены в сервисе.

## Период проживания

Промежуток между выбранными датами заезда и выезда.
Правила расчёта продолжительности определяются требованиями к продукту.

## Форма бронирования

Набор элементов для указания дат проживания, количества гостей и контактных данных.

## Бронирование

Закрепление домика за гостем на определённый период в соответствии с условиями сервиса.
Момент подтверждения определяется требованиями к будущей версии продукта.
Наличие кнопки **Забронировать** в макете не подтверждает реализацию этого процесса.

Термины «заявка», «заказ» и «бронирование» не взаимозаменяемы.
Для введения отдельной сущности сначала определите её значение.
