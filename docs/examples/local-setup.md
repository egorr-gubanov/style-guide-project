# Локальный запуск ЕГЭРывка

Инструкция предназначена разработчику, который хочет открыть интерфейс проекта
на своём компьютере. Она описывает запуск Next.js, а не проверку серверных функций.

## Требования

- Доступ к закрытому репозиторию `egorr-gubanov/ege_jerk`.
- Git, Node.js версии не ниже 20.9 и npm. Для работы выбирайте поддерживаемую ветку Node.js.
- Свободный локальный порт для сервера разработки.

Минимальная версия Node.js указана в документации Next.js; точные зависимости
проекта зафиксированы в `package-lock.json`.

## Порядок запуска

1. В каталоге, куда хотите сохранить проект, выполните:

    ```bash
    git clone https://github.com/egorr-gubanov/ege_jerk.git
    cd ege_jerk
    ```

    Ожидаемый результат: создан каталог `ege_jerk`, текущая папка — его корень.

2. В корне `ege_jerk` установите зависимости:

    ```bash
    npm ci
    ```

    Ожидаемый результат: npm завершит установку без ошибки.

3. Запустите сервер разработки:

    ```bash
    npm run dev
    ```

    Ожидаемый результат: терминал покажет адрес сервера.

4. Откройте адрес из терминала. Обычно это `http://localhost:3000/`.
    Для просмотра экрана диагностики добавьте к адресу путь `/diagnostic`.

## Остановка и частые проблемы

Остановите сервер сочетанием Ctrl+C в терминале, где он запущен.
Если Git отказывает в доступе, проверьте учётную запись и разрешения репозитория.
Если порт занят, используйте адрес, который фактически напечатал Next.js.
Если установка зависимостей завершилась ошибкой, сначала сохраните текст ошибки
и проверьте версии Node.js и npm.
