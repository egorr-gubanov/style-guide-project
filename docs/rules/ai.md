# ИИ и достоверность

## I01 ИИ как помощник автора

**Допустимо.** Используйте ИИ для первого варианта структуры, поиска расхождений
в терминах, предложений по сокращению текста и черновиков примеров.
В запрос передавайте цель, аудиторию, правила и только разрешённые исходные данные.

Пример запроса: «Проверь текст по M03 и S04. Для каждого замечания приведи
фрагмент и причину. Не добавляй функции, которых нет в источнике».
Результат проверяет автор. Для существенной генерации укажите её использование в PR.

## I02 Проверяемые утверждения

**Обязательно.** Сверяйте с исходниками каждое утверждение о функции продукта.
Отделяйте реализованную функцию, видимый макет и план. ИИ не является источником
доказательства работоспособности.

До: «Сервис гарантированно повысит результат на 25 баллов».
После: «В прототипе показан демонстрационный прогноз +25 баллов.
Методика прогноза и его точность не подтверждены».
Проверка: ручная сверка с кодом, испытанием или утверждённым требованием.

## I03 Исключения

**Обязательно.** Отступление от обязательного правила согласуйте в PR: укажите
идентификатор, причину, границы и проверяющего. Зафиксируйте решение рядом с изменением.
Исключение для одного документа не меняет правило для всего проекта.
Проверка: история PR и решение рецензента.
