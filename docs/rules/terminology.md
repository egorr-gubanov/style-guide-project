# Термины и названия

## T01 Единый глоссарий

**Обязательно.** Используйте утверждённый вариант термина в авторском тексте.
Точные надписи интерфейса цитируйте без исправлений, даже если они отличаются.

| Понятие | Пишем | Избегаем |
| --- | --- | --- |
| Название продукта | ЕГЭРывок | ЕГЭ Рывок, EGE Jerk |
| Предварительная проверка знаний | диагностика | квиз, чек знаний |
| Учебная единица | задание | задачка, таска |
| Область пользователя | личный кабинет | аккаунтная зона |
| Учебный итог | результат диагностики | гарантированный балл ЕГЭ |
| Изменение документа | Pull Request, затем PR | пулрик |

В исходном интерфейсе есть надпись «Вопрос 3 из 20». При описании экрана
сохраняйте эту надпись, а в авторском объяснении используйте слово «задание».
Проверка: ручное сравнение с глоссарием и интерфейсом.

## T02 Сокращения и идентификаторы

**Обязательно.** При первом использовании раскройте неизвестное аудитории
сокращение. Не переводите пути, команды, имена файлов и идентификаторы.

Пример: «Непрерывная интеграция (CI) запускает проверки для PR».
Имя `package.json` сохраняйте без перевода.
Проверка: ручное ревью первого употребления.
