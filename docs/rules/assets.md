# Код и изображения

## C01 Команды и фрагменты кода

**Обязательно.** Команды оформляйте в ограждённом блоке с языком `bash`,
настройки — с `yaml` или `json`. Имена файлов, путей и параметров выделяйте
моноширинным начертанием. Не добавляйте символ приглашения `$` в команды для копирования.

```bash
npm ci
npm run dev
```

Укажите каталог запуска и требуемые переменные. Вместо настоящего секрета
используйте явный заменитель `EXAMPLE_TOKEN`. Не выдавайте заменитель за рабочий ключ.
Проверка: язык блока проверяет линтер; команды и параметры сверяет рецензент.

## C02 Безопасный порядок действий

**Обязательно.** До команды с удалением или перезаписью данных объясните последствие
и необходимость резервной копии. Для учебных примеров выбирайте действия без удаления.

Пример: остановка сервера через Ctrl+C не требует удаления файлов проекта.
Проверка: ручная оценка команд, автоматический линтер её не заменяет.

## C03 Изображения

**Обязательно.** Информативному изображению дайте содержательное текстовое описание.
Скриншот дополняет инструкцию: шаги должны быть понятны и без него. Не помещайте
в изображения действительные персональные данные, пароли и токены.

Пример описания: «На экране диагностики кнопка Сохранить ответ находится под вариантами».
Проверка: линтер проверяет наличие alt-текста, рецензент — его полезность и актуальность.
