# Заполнение формы бронирования

## Назначение и аудитория

Инструкция предназначена для пользователя, который хочет указать сведения для бронирования домика
в сервисе «Сосны». Она описывает заполнение формы до отправки данных.

## Источник и статус

Источник — [макет сервиса «Сосны»](https://www.figma.com/design/Hrn06cbi1J6furVPfOIbso/ЛР1).
Документ предназначен для будущей реализации интерфейса. Выполнение действий необходимо проверить
после разработки формы. Обработка данных и подтверждение бронирования в область инструкции не входят.

## Предварительные условия

Выберите предполагаемые даты проживания и определите количество гостей.
Подготовьте имя, адрес электронной почты и номер телефона для связи.

## Порядок заполнения

1. Ознакомьтесь со сведениями о домике. Убедитесь, что выбран подходящий объект размещения.
2. В поле **Заезд** укажите предполагаемую дату начала проживания.
3. В поле **Выезд** укажите предполагаемую дату окончания проживания.
4. В поле **Количество гостей** укажите число проживающих.
5. В поле **Имя** укажите своё имя.
6. В поле **Почта** укажите адрес электронной почты для связи.
7. В поле **Телефон** укажите номер телефона для связи.
8. Проверьте даты проживания, количество гостей и контактные данные. При необходимости исправьте значения.
9. Сопоставьте сведения о домике и периоде проживания с показанной стоимостью.
   Если непонятно, за какой период указана сумма или что в неё включено, уточните условия до отправки формы.

## Ожидаемый результат

В форме указаны сведения о предполагаемом проживании и контактные данные пользователя.
Форма подготовлена к проверке перед отправкой. Этот результат предполагается для будущей реализации
и не является результатом выполненного тестирования.

## Если обнаружена ошибка

До отправки формы исправьте ошибочное значение и повторно проверьте сведения.

## Граница инструкции

В макете предусмотрена кнопка **Забронировать**. Документ не устанавливает результат её нажатия.
Сохранение данных, доступность домика, оплата, подтверждение бронирования и изменение отправленных сведений
требуют отдельных требований и проверки реализации.

Правила: [структура S01–S03](../rules/structure.md),
[названия T02](../rules/terminology.md), [достоверность D01](../rules/accuracy.md).
