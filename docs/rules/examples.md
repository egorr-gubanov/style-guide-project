# Изображения и технические примеры

Все правила раздела обязательны.

## C01 Скриншоты и описания изображений

**Требование.** Показывайте документируемую версию интерфейса и только необходимые элементы. Указатель мыши и посторонние окна не должны попадать в изображение. Для содержательного изображения добавляйте альтернативный текст, при необходимости — подпись.

**Обоснование.** Изображение должно помогать понять инструкцию и оставаться полезным без графического содержимого.

**Неправильно.** Скриншот рабочего стола с формой и посторонними окнами.

**Правильно.** Изображение формы с альтернативным текстом «Форма с датами проживания, количеством гостей и контактными данными».

**Проверка.** Наличие непустого альтернативного текста проверяется автоматически. Смысл, читаемость и отсутствие курсора проверяются визуально.

## C02 Команды и программные идентификаторы

**Требование.** Имена файлов, программные идентификаторы и отдельные команды оформляйте как встроенный код. Многострочные примеры помещайте в блоки кода с обозначением языка. Для выполняемой команды указывайте условия и ожидаемый результат.

**Обоснование.** Читатель должен отличать пояснение от текста, который нужно воспроизвести точно.

**Неправильно.** Выполните команду сборки — без команды и условий запуска.

**Правильно.** Из корня репозитория руководства при установленных зависимостях выполните `python -m mkdocs build --strict`. При успешной сборке каталог `site/` содержит готовый сайт.

**Проверка.** Оформление проверяется линтером. Соответствие команд проекту и результат выполнения проверяет автор.

## C03 Демонстрационные данные

**Требование.** Используйте вымышленные данные без паролей, токенов и персональных сведений реальных пользователей. Существенные демонстрационные значения обозначайте как примеры.

**Обоснование.** Примеры должны быть пригодны для публикации и не восприниматься как реальные бронирования.

**Неправильно.** Использовать в публичном примере адрес реального гостя или действующий ключ доступа.

**Правильно.** Пример адреса электронной почты: guest@example.com.

**Проверка.** Автор проверяет текст, изображения и приложения перед публикацией.
